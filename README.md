## 使用方法
· 在Releases里找到最新版本。下载除源码（source code）外的所有文件。

· 解压带APP字样压缩包，双击install文件。

· 选择安装地址，然后点击安装，直到安装完成。

· 初次打开软件，先配置API，然后选择下载的带Knowledge字样的压缩包。

· 然后就可以正式使用了。
